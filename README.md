# Luz desde tres puntos

Simulador interactivo para practicar el cableado de una bombilla controlada desde uno, dos o tres sitios (interruptor simple, dos conmutadores, o conmutador + cruzamiento + conmutador).

Conecta los cables tocando los tornillos, mira hasta dónde llega la fase y cómo circula la corriente cuando se cierra el circuito.

Es una sola página estática (`index.html`), publicada con GitHub Pages.
